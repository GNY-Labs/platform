# platform

Shared building blocks for the GNY Labs service repositories.

## Contents

- `templates/svc/`: the service template that every `svc-*` repository starts from.
- `.github/workflows/`: reusable CI workflows (YAML lint, gitleaks, hadolint, shellcheck).
- `docs/contract.md`: the service contract (v1) that every service follows.

## Status

Work in progress. Part of the [NewsPulse](https://github.com/gny-labs/newspulse) project.
